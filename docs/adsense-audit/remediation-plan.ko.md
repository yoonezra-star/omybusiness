# omybusiness AdSense 거절 진단과 보강 실행 계획

작성일: 2026-10-11. 갱신일: 2026-10-12. 상태: 대표 3개에 이어 추가 9개, 누적 우선 12개 본문 개정·로컬 검증 완료. 나머지 70개와 재심사 요청은 미완료. 배포·화면 검증 결과는 phase-1-results.ko.md 및 phase-2-results.ko.md에 기록한다.

## 1. 판단과 조사 범위

이번에 전달받은 거절 항목은 복제된 콘텐츠와 가치가 별로 없는 콘텐츠다. 우선순위는 본문 사실 검증, 글마다 구체적인 분석, 실제 외부 콘텐츠와의 중복 여부 확인이다. 이미지나 운영 페이지를 더 붙이는 작업만으로 이 두 항목의 해결을 입증하기 어렵다.

사용자가 확인한 이전 방식은 티스토리에 개인 도메인 omybusiness.com을 연결해 운영하다가 같은 도메인을 Cloudflare로 옮긴 것이다. 같은 도메인과 글 경로를 유지한 부분은 URL 변경 없는 호스팅 이전이다. 기존 본인의 글을 같은 사이트 주소에서 제공하는 것은 정상적인 이전이며, 원문을 유지했다는 사실만으로 복제 콘텐츠 위반이나 낮은 독창성을 판정하지 않는다. 실제 경로가 달라진 URL만 별도로 매핑한다. [Google 호스팅 변경 안내](https://developers.google.com/search/docs/crawling-indexing/site-move-no-url-changes?hl=ko)를 기본 이전 기준으로 적용한다.

티스토리 기본 주소가 현재도 공개된 사실은 별도의 표준 URL 점검 사항이다. 그것이 이번 거절 원인이라고 확인한 것은 아니다. 현재의 티스토리 canonical 관찰 결과로 이전 당시의 설정이나 Google이 실제 선택한 표준 URL을 추정하지 않는다.

이번 조사는 로컬 82개 글과 생성 HTML 111개를 전수 집계하고, 공개 티스토리 글 8개와 새 사이트의 같은 글 8개, 공통 참고자료 8개, 주요 사이트 URL 8개를 직접 조회했다. Chrome에서 홈페이지와 대표 글의 화면도 확인했다. 전체 인터넷에 대한 표절 검사, 82개 글의 모든 주장 사실 검증, 현재 Search Console/Analytics 계정의 성과 분석은 아직 수행하지 않았다.

Google은 거절 안내에서 문제가 된 개별 URL이나 내부 평가 점수를 알려주지 않았다. 아래 문제들은 직접 확인한 사실과 그에 따른 편집 판단이다. 실제 심사 원인을 단정하지 않는다. 본인 소유의 글을 이전했다는 사실만으로 타인의 콘텐츠를 도용했다고 볼 수 없다.

공식 기준은 [복제된 콘텐츠 정책](https://support.google.com/publisherpolicies/answer/11190248?hl=ko), [콘텐츠 및 사용자 환경 안내](https://support.google.com/adsense/answer/10015918?hl=ko), [사용자 중심 콘텐츠 안내](https://developers.google.com/search/docs/fundamentals/creating-helpful-content?hl=ko)를 참고했다. 출처만 나열하거나 문장을 바꾸는 작업보다 독자가 얻는 구체적 정보와 분석을 확인해야 한다.

## 3. 90점 이상을 위한 자체 평가표

이 표는 Google 공식 점수, 승인 확률, Lighthouse 점수가 아니다. 각 항목의 산출물과 검증 기록을 확인해 운영자가 평가하는 편집 품질표다. 계획의 목표 합계는 93/100점이다. 현재 점수는 전체 주장 검증과 운영자 확인이 끝나지 않아 확정하지 않는다.

| --- | ---: | ---: | --- |
| 독창성과 고유 분석 | 30 | 28 | 글별 구체적 자체 설명·분석 16점, 외부 자료와 구별되는 가치·목적이 겹치는 글의 차별화 14점. 본인 글의 정상적인 호스팅 이전은 감점 사유로 삼지 않음 |

점수는 근거가 완전히 확인되면 해당 점수를 부여하고, 일부만 충족하면 검증된 범위만 부여한다. 미확인 항목은 충족으로 처리하지 않는다. 모든 공개 콘텐츠를 평가하며 대표 글만 점검한 점수를 사이트 전체 점수로 쓰지 않는다. 일부 글이 낮은 품질인 상태를 좋은 대표 글의 평균 점수로 가리지 않는다.

점수와 별개로 미해결 복제·권리 문제, 근거 없는 핵심 수치, 확인하지 못한 전문 경험 주장, 검토하지 않은 공개 글이 남으면 재심사 준비 완료로 처리하지 않는다. noindex만 붙이면 AdSense 품질 문제가 해결된 것으로 평가하지 않는다.

## 4. 단계별 실행

### 1단계: 콘텐츠 전수 분류와 기존 URL 점검

예상 작업량: 1~2일. 현재 CSV 목록 작성까지 완료.

1. 82개 글에 유지·전면 재구성·통합 후보·발행 중단 검토 상태를 부여한다. 검색 의도, 정확성, 출처, 실제 독자 필요를 기준으로 결정한다.
2. 29개 경험 표현 플래그와 숫자·성과 주장을 P0 검토 목록으로 만든다. 자동 탐지 결과는 허위 판정이 아니므로 원문을 읽고 운영자에게 사실 여부를 확인한다.
3. 기존 omybusiness.com의 글 경로가 현재도 같은 본문으로 연결되는지 확인한다. 동일한 URL이면 옛 도메인에서 새 도메인으로 보내는 301이나 주소 변경 신청은 필요하지 않다. 실제로 변경된 경로에만 일대일 리디렉션을 검토한다. 기본 절차는 [Google 호스팅 변경 안내](https://developers.google.com/search/docs/crawling-indexing/site-move-no-url-changes?hl=ko)를 따른다.
4. 티스토리 기본 주소의 접근과 현재 canonical은 보조 점검으로 기록한다. Search Console에서 omybusiness.com 대표 글의 Google 선택 표준 URL과 중복 관련 상태를 먼저 확인한다. 원인이 확인되지 않은 상태에서 티스토리 글을 일괄 비공개로 전환하거나 재작성하지 않는다. 조정이 필요한 경우 티스토리의 실제 지원 기능을 확인하고 백업·기존 유입 영향을 검토한다. 티스토리 하위 도메인의 서버 응답은 새 Cloudflare 사이트에서 제어할 수 없다.
5. canonical은 검색엔진에 보내는 신호다. 편집 품질이나 AdSense 승인 보증이 아니다. robots.txt 차단으로 중복 처리를 대신하지 않는다. [Google 표준 URL 안내](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls?hl=ko)를 참고한다.

완료 기준: 82개 URL의 편집 상태를 기록하고, 동일 도메인에서 글 경로가 유지되는지와 실제 변경 경로의 연결을 확인한다. 티스토리 기본 주소의 표준화는 확인된 검색 상태를 근거로 필요한 경우에만 조정한다. 외부 설정 변경과 본문 비공개 작업은 아직 실행하지 않았다.

### 2단계: 글별 근거를 관리하는 구조 만들기

예상 작업량: 1~2일. 후속 본문 작업과 함께 진행 가능.

현재 build.js는 제목 키워드로 성숙도·리스크·참고자료를 선택한다. 이 결과를 사실 검토의 증거로 쓰지 않고, 글별 검증된 데이터가 화면을 결정하도록 변경한다.

- 글 데이터에 작성자 표시명, 편집 상태, 검토일, 사용 자료, 핵심 주장, 근거 위치, 수정 내역을 기록한다.
- 출처에는 문서 제목, 발행일, 실제 열람일, URL, PDF 쪽수 또는 웹 문단, 그 자료가 뒷받침하는 주장을 기록한다.
- 표에는 단위, 연도, 기준 범위, 발표된 수치인지 계산 예제인지 표시한다.
- 인용은 필요한 만큼만 짧게 사용하고 나머지는 자체 설명과 분석으로 작성한다.
- 사실은 자료에 근거해 쓰고, 추론은 추론이라고 표시한다. 확인되지 않은 부분은 보류하거나 한계를 적는다.

5. 모바일 성능은 반복 가능한 조건의 Lighthouse로 측정한다. 별도의 기술 목표는 주요 화면 성능 90 이상으로 잡되, 이 점수를 AdSense 콘텐츠 평가나 승인 확률로 해석하지 않는다. 실제 사용자 데이터가 있으면 그것도 확인한다.
6. 기존 Search Console에서 최근 28일·90일의 노출, 클릭, 유입 질문, 페이지별 현황을 확인한다. 독자가 어떤 질문으로 들어오고 무엇을 찾는지 콘텐츠에 반영한다. 현재 수치는 이번 조사에서 미확인이다.
7. 실제 이용 지표는 개선과 유지관리의 근거로 사용한다. 임의의 방문자 수, 체류 시간, CTR을 AdSense 공식 합격선으로 만들지 않는다. 유입을 구매하거나 인위적으로 클릭·재방문을 만들지 않는다.
8. 모든 공개 글 검토와 필수 통과 조건 완료 후 자체 점수를 계산한다. 90점 미만 또는 필수 문제 미해결이면 미완료 항목을 먼저 수정한다. 목표는 93점이다.
9. 검토 요청 전 마지막으로 거절 사유별 수정 기록을 확인하고, 실제 문제가 해결된 경우에만 '문제를 수정했음'을 표시하고 요청한다. 이번 작업에서는 이 확인이나 요청을 실행하지 않았다.

검색 색인 상태와 AdSense 승인 판단은 별개다. 색인 요청 완료, sitemap 성공, HTTP 200, ads.txt 존재만으로 승인 준비가 완료된 것으로 보지 않는다. 48~72시간이 지나면 반드시 색인되거나 승인된다는 일정도 적용하지 않는다.

## 5. 재심사 전 필수 통과 조건

- 82개 기존 글 모두 유지·개정·통합·발행 중단의 편집 결정과 이유가 기록됨.
- 최종 공개본의 핵심 숫자·성과·사업 단계·일정마다 독자가 찾아갈 수 있는 근거가 있음.
- 검증되지 않은 취재·현장 경험·경력 주장이 남지 않음.
- 동일 도메인에서의 호스팅 이전과 실제 경로 변경 여부가 기록됨. 티스토리 기본 주소에 필요한 조치가 있는지는 실제 표준 URL 상태를 근거로 판단함.
- 공개 유지한 글마다 다른 독자 질문과 구체적인 답변·분석이 있음.
- 이미지 권리와 제작 성격을 확인했고 도표의 근거·범위를 표시함.
- 허브·자료·도구가 실제 공개 콘텐츠와 연결되고 빈 페이지·가짜 기능이 없음.
- 실제 작성자·문의·수정 기록·서비스와 정책 설명이 일치함.
- 모바일·데스크톱·키보드 탐색, 링크·이미지·리디렉션·상태 코드 검증 완료.
- 자체 평가 90점 이상, 미해결 필수 문제 없음. 이 조건을 충족해도 최종 승인은 Google이 판단함.

## 6. 일정과 바로 다음 작업

전체 82개를 검증하고 본문을 재구성하는 데는 대략 2~4주 이상의 편집 작업을 예상한다. 각 단계는 작업량 추정이며 출처 확보, 작성자 사실 확인, 기존 서비스 설정의 제약에 따라 늘어날 수 있다. 단계 일부는 병행할 수 있고 검색 재처리와 AdSense 검토 시간은 포함하지 않았다.

지진파·산업 AI·화학 전략 3개 파일럿은 본문 개정과 로컬 검증을 완료했다. 다음 작업은 이 기준을 추가 9개 글에 적용하고 82개 목록의 편집 결정을 계속 기록하는 것이다. 티스토리 기본 주소는 실제 선택 표준 URL을 확인하는 보조 점검으로 다루며, 원인을 확인하지 않은 일괄 비공개 작업은 계획하지 않는다.

현재 완료된 산출물:

- evidence.json: 로컬 집계, 반복 문구, Tistory 8개 표본 비교, 참고자료·서비스 HTTP 조회 결과.
- content-inventory.csv: 82개 글의 ID, 제목, 현재·원본 URL, 분량, 근거 링크 수, 경험 검토 플래그, 우선 작업.
- scripts/audit-content.mjs: 같은 범위의 재진단을 수행하는 스크립트. 자동 결과는 사실 검증이나 표절 판정을 대신하지 않음.

evidence.json과 content-inventory.csv는 개정 전 진단 스냅샷이다. 현재 개정 상태는 data/article-reviews.json과 phase-1-results.ko.md를 함께 확인한다. 이번 본문 개정은 같은 도메인·경로의 기존 콘텐츠를 보강하는 작업이며, Tistory 글의 삭제·비공개나 AdSense 재심사 제출은 하지 않았다.
