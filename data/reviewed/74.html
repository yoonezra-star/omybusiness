Group III 기유를 사용한 윤활유는 모두 친환경일까? 기유 분류만으로는 그렇게 결론 내릴 수 없다. 기유는 완성 윤활유의 구성 재료이며, 실제 성능에는 첨가제와 배합, 제품 시험, 사용 조건이 함께 영향을 준다. 아람코의 제품군과 API 분류를 대조해 구매자가 구분해야 할 정보를 정리한다.

아람코가 판매하는 것은 기유 제품군이다

아람코는 aramcoDURA, aramcoPRIMA, aramcoULTRA 브랜드를 각각 API Group I, II, III 기유 제품군으로 소개한다. 관련 공급 계열사로 LUBEREF, Motiva, S-Oil을 설명한다. [1] 이 정보는 제품 공급과 분류의 근거이며, 모든 완성 윤활유의 연비나 수명을 입증하는 시험 결과가 아니다.

또한 같은 브랜드 계열에서 나온 공정유라도 API 기유 그룹으로 분류되지 않는 제품이 있을 수 있다는 회사 설명이 있다. 따라서 브랜드명만 보고 그룹을 추정하지 말고 개별 제품의 데이터시트와 분류를 확인해야 한다. 이 글은 특정 차량에 사용할 윤활유를 추천하거나 제품 간 현장 비교 시험을 했다고 주장하지 않는다.

API Group II와 III의 차이는 분류 기준에 있다

API 1509 제24판의 Annex E는 기유를 포화 성분, 황 함량, 점도지수 등으로 분류한다. 2026년 9월 23일 개정본에서 Group II와 III는 포화 성분과 황의 기준이 같고 점도지수 기준이 다르다. [2]

API 1509 Annex E의 Group I~III 요약 · 환경 인증 분류가 아니다
분류포화 성분황점도지수
Group I90% 미만 및/또는 황 기준 해당0.03% 초과 및/또는 포화 성분 기준 해당80 이상, 120 미만
Group II90% 이상0.03% 이하80 이상, 120 미만

Group I의 포화 성분과 황 조건은 “둘 다 반드시 해당”이 아니라 “하나 또는 둘에 해당”이라는 의미다. Group II·III의 황 기준 역시 “황이 없다”가 아니라 정해진 상한 이하라는 뜻이다. 점도지수는 온도에 따른 점도 변화의 특성을 나타내며, 그 숫자가 차량용 오일의 점도 등급이나 교환 주기 자체를 뜻하지는 않는다.

이 분류에서 직접 확인할 수 없는 것은 생분해성, 제품의 전 과정 온실가스 배출, 실제 차량 연료 절감률이다. Group III가 Group II보다 특정 물성 기준이 높다는 사실을 환경 부담이 언제나 더 작다는 주장으로 바꾸면 검증 범위를 넘어선다.

API 1509는 완성 엔진오일의 라이선스와 인증 표시를 다루는 문서이기도 하다. [2] 기유 그룹이라는 재료 정보와 완성 제품의 성능 표시는 층위가 다르다. 제조사의 요구 규격에 맞지 않는 제품을 기유 그룹만 보고 더 좋은 선택이라고 판단해서는 안 된다.

친환경 주장과 유지 비용을 비교하는 방법

연료 절감이나 교환 주기 연장이라는 주장이 나오면 동일한 장비·운전 조건인지부터 확인한다. 오일 가격만 비교하면 정비 비용과 사용량을 놓치고, 교환 주기만 비교하면 장비에 허용된 주기를 넘길 수 있다. 제품 설명의 조건과 실제 사용 조건이 다르면 시험 결과를 그대로 적용할 수 없다.

비용을 비교할 때 사용할 틀

기간 비용 = 오일 구매 + 교환 작업 + 점검·분석 + 제품 변경으로 확인된 추가 비용. 연료비 차이는 같은 작업량과 조건으로 측정했을 때만 별도로 반영한다. 확인되지 않은 수명 연장이나 고장 감소를 절감액에 넣지 않는다.

환경적 비교에도 같은 원칙이 적용된다. 제조 단계만 비교한 결과인지, 운행 중 연료 변화와 폐유 처리까지 포함한 결과인지 적어야 한다. 마케팅 문구가 “저황” 또는 “고순도”에 머무른다면 그 특성은 설명할 수 있어도 전 과정 친환경이라는 결론은 보류하는 편이 정확하다.

아람코의 기유 사업은 원유를 다양한 윤활 재료로 공급하는 산업 활동으로 이해할 수 있다. 독자에게 유용한 정보는 그룹별 우열 선언보다 재료 분류, 완성 제품 적합성, 환경 주장의 근거를 각각 확인하는 순서다. 이전 글의 개인 사용담과 일률적 성능 향상 수치는 이 기준에 맞는 자료가 없어 사용하지 않았다.
